Corollary SI.7 (Phases of the accuracy-exponent map)
Under the hypotheses of Theorem SI.15:
  1. (a)
    Phase A, \(\alpha>2\), \(\texp\le\alpha+1\): SignSVD wins for every \(\omega\).
  2. (b)
    Phase B, \(0<\alpha<1\) and \(\texp\ge1\) with \((\alpha,\texp)\notin\mathsf E\), or \(1<\alpha<2\) and \(\texp>2\alpha-1\): SignSGD wins for every \(\omega\).
  3. (c)
    Phase C, \(1<\alpha<2\), \(\texp<2\alpha-1\): SignSGD wins if \(\omega<\omega_c\) and SignSVD wins if \(\omega>\omega_c\); at \(\omega=\omega_c\) the two are balanced if \(\texp\ne1\), and SignSGD wins, with order \(1/\log N\), if \(\texp=1\).
  4. (d)
    Phase D, \(0<\alpha<1\), \(\texp<1\): SignSGD wins if \(\omega<p-1\), and the two are balanced if \(\omega\ge p-1\), with limit \(K_A\) if \(\omega>p-1\).
  5. (e)
    Tie, \(\alpha>2\), \(\texp>\alpha+1\): balanced for every \(\omega\).
  6. (f)
    Chord, \(1<\alpha<2\), \(\texp=2\alpha-1\): SignSGD wins if \(\omega<p-1\), and the two are balanced if \(\omega\ge p-1\), with limit \(K_c\) if \(\omega>p-1\).
  7. (g)
    \(\alpha=1\): for \(\texp<1\), SignSGD wins if \(\omega<p-1\) and SignSVD wins, with order \(\log N\), if \(\omega\ge p-1\); for \(\texp=1\), SignSGD wins if \(\omega<1\), and \(\mathsf R\to\pi^{3/2}\) if \(\omega>1\); for \(1<\texp<2\), SignSGD wins for every \(\omega\).
  8. (h)
    \(\alpha=2\): SignSVD wins for \(\texp<3\), the two are balanced for \(\texp=3\), and SignSGD wins for \(\texp>3\), for every \(\omega\).
Proof of Corollary SI.7.
For \((\alpha,\texp)\notin\mathsf E\) use Theorem SI.15(ii): the winner is SignSVD if \(S(\omega)>0\) and SignSGD if \(S(\omega)<0\); if \(S(\omega)=0\), it is SignSVD if \(L>0\), SignSGD if \(L<0\), and the two are balanced if \(L=0\). Write \(\omega'\defeq\min\{\omega,p-1\}\) and use (SI.48).
For \(0<\alpha<1\), \(e_D=-\frac\alpha2\). If \(\texp<1\), then \(S(\omega)=\frac\alpha2(\omega'/(p-1)-1)\) and \(L=0\), which gives Phase D, with the limit \(K_A\) from Theorem SI.15(i). If \(\texp\ge1\), then \(\alpha+1-\texp\le\alpha\), so \(S(\omega)\le0\), with equality only at \(\texp=1\), \(\omega\ge p-1\), where \(L=-1\); this gives the first part of Phase B.
For \(\alpha=1\), \(e_D=-\frac12\) and \([\alpha=1]=1\). If \(\texp<1\), then \(S(\omega)=\frac12(\omega'/(p-1)-1)\) and \(L=1\). If \(1\le\texp<2\), use Theorem SI.15(iii): \(S(\omega)=-\frac12+\frac{\omega'}{p-1}\cdot\frac{2-\texp}2<0\) unless \(\texp=1\) and \(\omega\ge p-1\), so the upper bound forces \(\mathsf R\to0\) for \(\omega<p-1\) and for \(1<\texp<2\). At \(\texp=1\) and \(\omega>1\) use Theorem SI.15(i) and Theorem SI.12(b).
For \(1<\alpha<2\), \(e_D=\frac\alpha2-1<0\) and \(L=-[\texp=1]\), since \(\texp=\alpha+1\) gives \(S(\omega)=e_D<0\). If \(\texp<1\), then \(S(\omega)>0\) exactly when \(\omega'>(2-\alpha)(p-1)/\alpha=\omega_c\), and \(\omega_c<p-1\). If \(1\le\texp\le\alpha+1\), then
\[ S(\omega)=\frac\alpha2-1+\frac{\omega'}{p-1}\cdot\frac{\alpha+1-\texp}2 , \]
which vanishes at \(\omega'=\omega_c\); and \(\omega_c<p-1\) exactly when \(\texp<2\alpha-1\). On the chord \(S(\omega)<0\) for \(\omega<p-1\) and \(S(\omega)=0\), \(L=0\) for \(\omega\ge p-1\), with the limit \(K_c\) from Theorem SI.15(i). Above the chord and for \(\texp>\alpha+1\), \(S(\omega)<0\). This gives Phase C, the chord and the second part of Phase B.
For \(\alpha=2\), \(e_D=0\); \(S(\omega)>0\) for \(\texp<3\), and \(S(\omega)=0\) for \(\texp\ge3\) with \(L=-1+[\texp=3]\). For \(\alpha>2\), \(e_D=0\); \(S(\omega)>0\) for \(\texp<\alpha+1\), and for \(\texp\ge\alpha+1\), \(S(\omega)=0\) with \(L=[\texp=\alpha+1]\). This gives Phase A and the Tie.
□
