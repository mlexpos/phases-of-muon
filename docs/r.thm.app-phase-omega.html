Theorem SI.15 (Accuracy-exponent map)
Fix \(\alpha>0\), \(\texp\) with \(p=\alpha+\texp>1\), \(\omega>0\) and \(T\ge4\). As \(N\to\infty\):
  1. (i)
    if \(\omega>p-1\), then \(\mathsf R\sim\rho_N\), so every conclusion of Theorem SI.12 and Corollary SI.4 holds for \(\mathsf R\);
  2. (ii)
    if \((\alpha,\texp)\notin\mathsf E\), then \(\mathsf R\asymp N^{S(\omega)}(\log N)^L\);
  3. (iii)
    if \(\alpha=1\) and \(1\le\texp<2\), then \(\mathsf R\lesssim N^{S(\omega)}(\log N)^L\).
Proof of Theorem SI.15.
For \(\omega>p-1\), \(x=N^{-(\omega-(p-1))}\to0\), and Theorem SI.13 applies. Both models lie in \(\mathcal U\) exactly when \((\alpha,\texp)\notin\mathsf E\): SignSVD fails only at \(\alpha=1\), \(\texp\ge1\), and SignSGD only at \(\alpha\in\{\frac12,1\}\), \(\texp\ge\alpha+1\). For \(\alpha=1\) and \(1\le\texp<2\) only SignSGD lies in \(\mathcal U\). Apply Corollary SI.6; for large \(N\), \(N^{-\omega}<\epsilon_0\).
□
