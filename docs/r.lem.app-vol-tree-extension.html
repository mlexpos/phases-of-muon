Lemma SD.10 (Extension to continuous filters)
Fix \((\ell,J,R)\) and diagonal \(F,G\) with \(\norm F,\norm G\le1\). Write \(\norm f_D\defeq\sup_{\abs x\le D}\abs{f(x)}\).
  1. (i)
    For odd polynomials \(f_1,f_2\), \(\abs{\mathfrak R^{J,R}_\ell[F,G](f_1,f_2)}\le\gamma_\star\norm{f_1}_{D_R}\norm{f_2}_{D_R}\).
  2. (ii)
    The response extends uniquely to a bilinear functional on pairs of odd continuous functions on \([-D_R,D_R]\) with the same bound. The extension is linear in \(F\) and in \(G\) and unchanged under replication.
  3. (iii)
    For odd bounded continuous \(f_1,f_2\) on \(\R\), under the size conditions,
    \[ \sup_{F,G}\abs{\EE\,\mathcal K^{F,G}[f_1,f_2](\mathsf K_1,\mathsf K_2)-\mathfrak R^{J,R}_\ell[F,G](f_1,f_2)}\longrightarrow0 , \]
    the supremum over diagonal \(F,G\) of norm at most one; the convergence is uniform over \((f_1,f_2)=(\iota_s,\iota_u)\) with \(s,u\) in a compact subset of \((0,\infty)\), and over \((f_1,f_2)=(\omega_\ridge,\omega_{\ridge'})\) with \(\ridge,\ridge'\in I\).
Proof.
For (i), fix the finite dimension and consider its replications. By Lemma SD.8 at order \(N\), whose constant does not depend on \(N\), and the replication invariance,
\[ \mathfrak R^{J,R}_\ell[F,G](f_1,f_2)=\lim_{N\to\infty}\EE\,\mathcal K^{F^{(N)},G^{(N)}}[f_1,f_2]\big(\mathsf K_1^{(N)},\mathsf K_2^{(N)}\big). \]
On the event \(\mathcal E\) of Lemma SD.9 the singular values of \(\mathsf K_l^{(N)}\) are at most \(D_R\), so \(f_l^\sharp\) only sees \(f_l\) on \([-D_R,D_R]\), and (SD.8) bounds the contraction by \(\gamma_\star\norm{f_1}_{D_R}\norm{f_2}_{D_R}\); the same constant \(D_R\) serves for every \(N\). Off \(\mathcal E\) the contraction is bounded by \(\gamma_\star\) times a polynomial in \(\norm{\mathsf K_1^{(N)}},\norm{\mathsf K_2^{(N)}}\), whose expectation on \(\mathcal E^c\) tends to zero by Lemma SD.9. This proves (i).
For (ii), the Weierstrass theorem [92, Theorem 7.26] gives polynomials \(P_n\) converging to an odd continuous \(f\) uniformly on \([-D_R,D_R]\), and the odd parts \((P_n(x)-P_n(-x))/2\) converge to \(f\) as well. By (i) and bilinearity, the responses of approximating pairs form a Cauchy sequence, and two approximating sequences give the same limit. Linearity in \(F,G\) and replication invariance hold for polynomials by Definition SD.4 and Lemma SD.8, and pass to the limit.
For (iii), let \(\epsilon>0\) and choose odd polynomials \(p_1,p_2\) with \(\norm{f_l-p_l}_{D_R}\le\epsilon\). On \(\mathcal E\), (SD.10) (with the sup norms over \([-D_R,D_R]\)) bounds \(\abs{\mathcal K^{F,G}[f_1,f_2]-\mathcal K^{F,G}[p_1,p_2]}\) by \(\gamma_\star\epsilon(\norm{f_2}_\infty+\norm{p_1}_{D_R})\). Off \(\mathcal E\), \(\abs{\mathcal K[f_1,f_2]}\le\gamma_\star\norm{f_1}_\infty\norm{f_2}_\infty\) and the polynomial contraction has vanishing expectation by Lemma SD.9. The polynomial contraction is within \(C/B\) of \(\mathfrak R^{J,R}_\ell[F,G](p_1,p_2)\) by Lemma SD.8, and the latter is within \(\gamma_\star\epsilon(\norm{f_2}_{D_R}+\norm{p_1}_{D_R})\) of \(\mathfrak R^{J,R}_\ell[F,G](f_1,f_2)\) by (ii). All bounds are uniform over \(F,G\), so the limit superior of the supremum is at most \(C\epsilon\). Uniformity in the parameters follows from a finite mesh, since both sides are Lipschitz in the parameters, by (SD.10) and (SD.6) and (ii).
□

theorem lem_app_vol_tree_extension_ii (cert : Muon.External.GaussianOpNorm) (γstar CSig : ℝ)
    {m n B : ℕ} (Fp : FrozenParams m n B) (S : SpectralData Fp.C) (hS : SizeFin Fp.C B γstar CSig)
    (ℓ J : ℕ) (R : ℝ) (D : ℝ) (hD : volDR cert R CSig γstar ≤ D) (f g : ℝ → ℝ)
    (hfc : ContinuousOn f (Set.Icc (-D) D)) (hfo : ∀ x ∈ Set.Icc (-D) D, f (-x) = -f x)
    (hgc : ContinuousOn g (Set.Icc (-D) D)) (hgo : ∀ x ∈ Set.Icc (-D) D, g (-x) = -g x) :
    -- (a) existence: the polynomial responses converge to the extension, for all test entries
    (∀ (Fd : Fin m → ℝ) (Gd : Fin n → ℝ),
      Tendsto (fun k : ℕ => def_app_vol_tree Fp.β ℓ J R B S.μ S.lam Fd Gd
          (treeApprox D f k) (treeApprox D g k)) atTop
        (𝓝 (treeRespExt Fp.β ℓ J R B S.μ S.lam Fd Gd D f g))) ∧
    -- (b) the bound on the extension, for diagonal tests of norm at most one
    (∀ (Fd : Fin m → ℝ) (Gd : Fin n → ℝ) (Fm : Mat m m) (Gm : Mat n n),
      Fm = S.uOut * Matrix.diagonal Fd * S.uOutᵀ → Gm = S.vIn * Matrix.diagonal Gd * S.vInᵀ →
      opNorm Fm ≤ 1 → opNorm Gm ≤ 1 →
      |treeRespExt Fp.β ℓ J R B S.μ S.lam Fd Gd D f g| ≤
        γstar * supOn D f * supOn D g) ∧
    -- (c) replication invariance (eigenvalues repeated N times, batch N * B)
    (∀ (N : ℕ), 0 < N → ∀ (Fd : Fin m → ℝ) (Gd : Fin n → ℝ),
      treeRespExt Fp.β ℓ J R (N * B) (replVec N S.μ) (replVec N S.lam) (replVec N Fd)
          (replVec N Gd) D f g =
        treeRespExt Fp.β ℓ J R B S.μ S.lam Fd Gd D f g) ∧
    -- (d) linearity in the output and in the input diagonal entries
    (∀ (c : ℝ) (Fd₁ Fd₂ : Fin m → ℝ) (Gd : Fin n → ℝ),
      treeRespExt Fp.β ℓ J R B S.μ S.lam (fun i => c * Fd₁ i + Fd₂ i) Gd D f g =
        c * treeRespExt Fp.β ℓ J R B S.μ S.lam Fd₁ Gd D f g +
          treeRespExt Fp.β ℓ J R B S.μ S.lam Fd₂ Gd D f g) ∧
    (∀ (c : ℝ) (Fd : Fin m → ℝ) (Gd₁ Gd₂ : Fin n → ℝ),
      treeRespExt Fp.β ℓ J R B S.μ S.lam Fd (fun j => c * Gd₁ j + Gd₂ j) D f g =
        c * treeRespExt Fp.β ℓ J R B S.μ S.lam Fd Gd₁ D f g +
          treeRespExt Fp.β ℓ J R B S.μ S.lam Fd Gd₂ D f g) ∧
    -- (e) bilinear extension: linearity in the first and in the second function
    (∀ (c : ℝ) (f' : ℝ → ℝ), ContinuousOn f' (Set.Icc (-D) D) →
      (∀ x ∈ Set.Icc (-D) D, f' (-x) = -f' x) → ∀ (Fd : Fin m → ℝ) (Gd : Fin n → ℝ),
      treeRespExt Fp.β ℓ J R B S.μ S.lam Fd Gd D (fun x => f x + c * f' x) g =
        treeRespExt Fp.β ℓ J R B S.μ S.lam Fd Gd D f g +
          c * treeRespExt Fp.β ℓ J R B S.μ S.lam Fd Gd D f' g) ∧
    (∀ (c : ℝ) (g' : ℝ → ℝ), ContinuousOn g' (Set.Icc (-D) D) →
      (∀ x ∈ Set.Icc (-D) D, g' (-x) = -g' x) → ∀ (Fd : Fin m → ℝ) (Gd : Fin n → ℝ),
      treeRespExt Fp.β ℓ J R B S.μ S.lam Fd Gd D f (fun x => g x + c * g' x) =
        treeRespExt Fp.β ℓ J R B S.μ S.lam Fd Gd D f g +
          c * treeRespExt Fp.β ℓ J R B S.μ S.lam Fd Gd D f g') ∧
