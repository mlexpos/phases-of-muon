Remark SB.2 (No scalar effective batch for \(\bmom>0\))
By Lemma SB.1(ii), the value and the slope of \(F_w\) at \(0\) are \(\sw2\) and \(-3\sw4\). For \(K\) equal weights, \(\sw4/\sw2^{\,3}=1\), so a uniform average over \(K\) batches, equivalently a batch of size \(KB\) by Proposition SB.2(ii), is determined to first order at \(q=0\) by \(\sw2\) alone. For the EMA weights with \(\bmom\in(0,1)\),
\[ \frac{\sw4}{\sw2^{\,3}}=\frac{(1+\bmom)^2}{1+\bmom^2}>1,\qquad \frac{\sw3}{\sw2^{\,2}}=\frac{(1+\bmom)^2}{1+\bmom+\bmom^2}>1 , \]
so no choice of an effective batch size \(B_{\mathrm{eff}}=B/\sw2\) reproduces the function \(F_{\bmom}\), nor \(L_{\bmom}\), beyond the value at \(q=0\). This is why the system is stated with the full weight sequence.
