Lemma SB.10 (Variance of normalized traces)
Let \(T\in\mathbb{C}^{\Nout\times\Nout}\) be deterministic with \(\norm T\le C_T\) and put \(Y(s)\defeq\frac1B\Tr\big(TR(-s)\big)\). Then \(\Var Y(s)\le C_IC_T^2\,\sw2/B\) for \(s\in I\). The same bound holds for \(\frac1B\Tr(\widetilde TR_s(\Mt^\T))\) with \(\norm{\widetilde T}\le C_T\), and for the traces of the resolvents of any buffer with one sample deleted.
Proof.
The variance is controlled by the Efron–Stein inequality for a truncated history, and the truncation is removed by an \(L^2\) limit. For \(J\ge0\) let
\[ M^{(J)}\defeq\sum_{j\le J}\sum_{a=1}^B\mathsf h_{ja}\,\mathsf u_{ja}\tensor\mathsf v_{ja},\qquad Y^{(J)}\defeq\frac1B\Tr\big(TR_s(M^{(J)})\big), \]
so that \(Y^{(J)}\) is a function of the \(B(J+1)\) independent samples of ages \(0,\dots,J\).
The effect of one replaced sample is bounded through the nuclear norm. Replacing the sample \((j,a)\) by an independent copy \((d',\mathsf u',\mathsf v')\) produces \(Y^{(J),(ja)'}\) and changes \(M^{(J)}\) by the rank-two matrix \(\emaw j(d\,\mathsf u\tensor\mathsf v-d'\,\mathsf u'\tensor\mathsf v')\), whose nuclear norm is at most \(\emaw j(\abs d\norm{\mathsf u}\norm{\mathsf v}+\abs{d'}\norm{\mathsf u'}\norm{\mathsf v'})\). By trace duality \(\abs{\Tr(TX)}\le\norm T\norm X_*\) and Lemma SB.9,
\[ \big|Y^{(J)}-Y^{(J),(ja)'}\big|\le\frac{C_T}{B}\cdot\frac{2}{s^{3/2}}\,\emaw j\big(\abs d\norm{\mathsf u}\norm{\mathsf v}+\abs{d'}\norm{\mathsf u'}\norm{\mathsf v'}\big), \]
and by Lemma SB.6 and the triangle inequality in \(L^2\),
\[ \big\|Y^{(J)}-Y^{(J),(ja)'}\big\|_2\le\frac{C_T}{B}\cdot\frac{2}{s_-^{3/2}}\,\emaw j\cdot2\cdot7C_\Sigma\gamma_\star=\frac{C_IC_T\,\emaw j}{B}. \]
The Efron–Stein inequality [13, Theorem 3.1] then gives
\[ \Var Y^{(J)}\le\frac12\sum_{j\le J}\sum_{a=1}^B\EE\big[(Y^{(J)}-Y^{(J),(ja)'})^2\big] \le\frac12\sum_{j\le J}B\,\frac{C_I^2C_T^2\emaw j^2}{B^2}\le\frac{C_I^2C_T^2\sw2}{2B}. \]
The truncation is removed at fixed dimension. By Lemma SB.9, trace duality, and \(\norm E_*\le\sqrt{\min(\Nout,\Nin)}\norm E_\F\),
\[ \big|Y-Y^{(J)}\big|\le\frac{C_T}{B}\cdot\frac{2}{s^{3/2}}\sqrt{\min(\Nout,\Nin)}\,\norm{\Mt-M^{(J)}}_\F , \]
and \(\EE\norm{\Mt-M^{(J)}}_\F^2\to0\) as \(J\to\infty\). Indeed, the batches of different ages are independent with the common mean \(\EE\Gt\) and the common Frobenius variance \(\mathsf V_B\) of Lemma SA.4, so
\[ \EE\norm{\Mt-M^{(J)}}_\F^2=\Big(\sum_{j>J}\emaw j\Big)^2\norm{\EE\Gt}_\F^2+\sum_{j>J}\emaw j^2\,\mathsf V_B , \]
and both tail sums vanish as \(J\to\infty\) because \(\sum_j\emaw j\le1\). (For the EMA weights this is Lemma SA.6(i).) Hence \(Y^{(J)}\to Y\) in \(L^2\), and
\[ \Var Y=\lim_{J\to\infty}\Var Y^{(J)}\le\frac{C_I^2C_T^2\sw2}{2B}. \]
The input side is the same argument for \(\Mt^\T=\sum_{j,a}\mathsf h_{ja}\,\mathsf v_{ja}\tensor\mathsf u_{ja}\), and deleting one sample removes one term from the Efron–Stein sum.
□

theorem lem_app_de_variance_i (I : Set ℝ) (hI : IsCompact I) (hIpos : I ⊆ Set.Ioi 0)
    (CSig γ : ℝ) :
    ∃ C : ℝ, 0 ≤ C ∧
      ∀ (m n B : ℕ) (w : ℕ → ℝ), WeightClass w →
      ∀ (Ω' : Type) [MeasurableSpace Ω'] (P : Measure Ω') [IsProbabilityMeasure P]
        (F : FrozenParams m n B) (S : FrozenSamples P m n B) (t : ℤ),
        opNorm F.C.Sout ≤ CSig → opNorm F.C.Sin ≤ CSig →
        (m : ℝ) ≤ γ * B → (n : ℝ) ≤ γ * B →
        ∀ s ∈ I, ∀ (T : Matrix (Fin m) (Fin m) ℂ) (CT : ℝ), opNorm T ≤ CT →
          cVar P (fun ω => normTrace T B (Rs (WeightedBuf w F S t ω) s)) ≤
            ENNReal.ofReal (C * CT ^ 2 * sumPow w 2 / B) := by
