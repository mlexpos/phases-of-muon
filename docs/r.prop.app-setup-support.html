Proposition SA.5 (Support event and zero risk)
In Definition SA.1 let \(P_{\mathrm{out}}\defeq\sum_{\mu_i>0}u_i\tensor u_i\) and \(P_{\mathrm{in}}\defeq\sum_{\lambda_j>0}v_j\tensor v_j\). There is an event \(\Omega_t\) of probability one, determined by the batch of step \(t\), on which
\begin{equation}\tag{SA.25} \Xout^{(a)}=P_{\mathrm{out}}\Xout^{(a)},\qquad \Xin^{(a)}=P_{\mathrm{in}}\Xin^{(a)}\quad(a\le B),\qquad \Gt^\circ=P_{\mathrm{out}}\Gt^\circ P_{\mathrm{in}} \end{equation}
for every value of \(\Dt\). On \(\Omega_t\), if \(\cR(t)=0\) then \(d_a^\circ=0\) for every \(a\) and \(\Gt^\circ=0\). If, in Definition SA.2, \(M_{-1}^\circ=P_{\mathrm{out}}M_{-1}^\circ P_{\mathrm{in}}\), then on \(\bigcap_t\Omega_t\) every buffer and every update satisfy \(M_t^\circ=P_{\mathrm{out}}M_t^\circ P_{\mathrm{in}}\) and \(\Gtilde^\circ=P_{\mathrm{out}}\Gtilde^\circ P_{\mathrm{in}}\), and \(\CMscr Q_{ij}(\Dt)\) is constant in \(t\) for every pair with \(\mu_i\lambda_j=0\).
Proof.
A zero eigenvalue is a direction of zero variance. If \(\mu_i=0\) then \(\EE(u_i^\T\Xout^{(a)})^2=u_i^\T\Sigmaout u_i=0\), so \(u_i^\T\Xout^{(a)}=0\) almost surely, and likewise \(v_j^\T\Xin^{(a)}=0\) almost surely when \(\lambda_j=0\). Let \(\Omega_t\) be the complement of the finite union of these null events over the zero modes and the samples. On \(\Omega_t\) each \(\Xout^{(a)}\tensor\Xin^{(a)}\) equals \(P_{\mathrm{out}}(\Xout^{(a)}\tensor\Xin^{(a)})P_{\mathrm{in}}\), which gives the last identity of (SA.25) for every \(\Dt\).
Zero risk forces zero residuals on \(\Omega_t\). By Lemma SA.1, \(\cR(t)=0\) exactly when \(P_{\mathrm{out}}\Dt P_{\mathrm{in}}=0\), since \(P_{\mathrm{out}}\Dt P_{\mathrm{in}}=\sum_{\mu_i\lambda_j>0}(u_i^\T\Dt v_j)\,u_i\tensor v_j\). On \(\Omega_t\) each residual is \(d_a^\circ=(\Xout^{(a)})^\T P_{\mathrm{out}}\Dt P_{\mathrm{in}}\Xin^{(a)}\), which vanishes, and then \(\Gt^\circ=0\).
The support property propagates through the algorithm by induction. If \(M_{t-1}^\circ=P_{\mathrm{out}}M_{t-1}^\circ P_{\mathrm{in}}\) then \(M_t^\circ=\bmom M_{t-1}^\circ+(1-\bmom)\Gt^\circ\) has the same property on \(\Omega_t\), and Lemma SA.2(ii) transfers it to \(\Qridge{\ridgephys_t}(M_t^\circ)\). For a pair with \(\mu_i=0\) or \(\lambda_j=0\) this gives \(u_i^\T\Gtilde^\circ v_j=0\), hence \(u_i^\T\Delta_{t+1}v_j=u_i^\T\Dt v_j\).
□
