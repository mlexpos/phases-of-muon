Definition SD.4 (Tree moment equations)
Fix \((\ell,J,R)\), diagonal \(F,G\), and integers \(a,b\ge0\), with \(k=2a+2b+2\) and the factors \(X_r\) and labels \(l_r\) of (SD.46).
  1. (1)
    The polygon. Take \(k\) external vertices \(\mathsf e_1,\dots,\mathsf e_k\) and \(k\) latent vertices \(\mathsf l_1,\dots,\mathsf l_k\), indices modulo \(k\). The vertex \(\mathsf e_r\) sits between \(X_r\) and \(X_{r+1}\); it has the input type if \(X_r\) is untransposed and the output type otherwise. The output vertex \(\mathsf e_k\) carries the mark \(F\) and the input vertex \(\mathsf e_{2a+1}\) carries the mark \(G\). Each factor \(X_r\) contributes a \(z\)-edge joining \(\mathsf l_r\) to the output vertex among \(\mathsf e_{r-1},\mathsf e_r\), and a \(w\)-edge joining \(\mathsf l_r\) to the input vertex among them.
  2. (2)
    Pairings. A pairing is a pair \((\pi,\pi')\) of a perfect matching \(\pi\) of the \(k\) \(z\)-edges and a perfect matching \(\pi'\) of the \(k\) \(w\)-edges. For each matched pair of edges, identify their two latent endpoints and their two external endpoints. The quotient multigraph has one edge for each matched pair, hence \(k\) edges, and it is connected. The pairing is retained if the quotient is a tree, that is, if it has exactly \(k+1\) vertices.
  3. (3)
    Values. For a retained pairing, every vertex class \(V\) of the quotient contributes a factor. An output class \(V\) containing \(p_V\) original external vertices contributes \(B^{-1}\sum_i\mu_i^{p_V}F_i^{m_V}\), where \(m_V=1\) if \(\mathsf e_k\in V\) and \(m_V=0\) otherwise. An input class contributes \(B^{-1}\sum_j\lambda_j^{p_V}G_j^{n_V}\), with \(n_V=1\) if \(\mathsf e_{2a+1}\in V\) and \(n_V=0\) otherwise. A latent class \(V\) with set of factors \(S_V\subset\{1,\dots,k\}\) contributes
    \[ m_{\abs{S_V}}(R)\sum_{\alpha\in\mathcal A}\prod_{r\in S_V}\varpi_{l_r,\alpha}. \]
  4. (4)
    The response. \(\mathfrak R^{J,R}_\ell[F,G](x^{2a+1},x^{2b+1})\) is the sum, over the retained pairings, of the products of the factors of their classes. It is extended bilinearly to pairs of odd polynomials.
