Definition SA.2 (The algorithm)
Fix a momentum \(\bmom\in[0,1)\), a normalized ridge \(\ridge>0\), a deterministic step sequence \((\lr_t)_{t\ge0}\) with \(\lr_t\ge0\), an initial parameter \(W_0\) and an initial buffer \(M_{-1}^\circ\in\R^{\Nout\times\Nin}\), both given before the first batch is drawn (the default is \(M_{-1}^\circ=0\)). Let \(t_{\mathrm{stop}}\defeq\inf\{t\ge0:\cR(t)=0\}\in\{0,1,\dots\}\cup\{\infty\}\). The algorithm is, for \(t\ge0\),
\begin{equation}\tag{SA.15} \begin{gathered} M_t^\circ=\bmom\,M_{t-1}^\circ+(1-\bmom)\,\Gt^\circ,\qquad W_{t+1}=\Wt-\lr_t\,\Gtilde^\circ,\\ \Gtilde^\circ\defeq\begin{cases}\Qridge{\ridgephys_t}(M_t^\circ),&t<t_{\mathrm{stop}},\\ 0,&t\ge t_{\mathrm{stop}},\end{cases} \qquad \ridgephys_t\defeq2\cR(t)\,\ridge . \end{gathered} \end{equation}
