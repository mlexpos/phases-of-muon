Corollary SI.5 (Extended main-range window)
Let \(\alpha>1\), \(\texp\ge1\) and \(T\ge4\). There are \(N_0\), \(\epsilon_0>0\) and \(0<c_-\le c_+\) such that for all \(N\ge N_0\), \(B\ge N\) and \(0<\epsilon<\epsilon_0\) with \(\epsilon\ge\epsilon_N\), both first hits are attained and, for both \(j\),
\[ c_-\le\frac{t^j_{T\epsilon}}{\mathcal S_jT_0^j\,\Pi_{r_j}(\epsilon)}\le c_+ . \]
Proof of Corollary SI.5.
For \(\alpha>1\) every triple \((\alpha,\texp,j)\) lies in \(\mathcal U\). Let \(x=\epsilon/\epsilon_N\ge1\). If \(r_j<1\), then
\[ \epsilon^{-(1-r_j)/(2r_j)}=x^{-(1-r_j)/(2r_j)}N^{q_j(1-r_j)}\le N^{q_j(1-r_j)}, \]
so \(\Upsilon_j=\epsilon^{-(1-r_j)/(2r_j)}\) and \(\epsilon^{-1/2}\Upsilon_j=\Pi_{r_j}(\epsilon)\). If \(r_j=1\), then \(p-1=2q_j\) gives \(\mathsf y_j=x\ge1\), so \(\log(1/\epsilon)\le2q_j\log N\) and \(\Upsilon_j\asymp\log(1/\epsilon)\). If \(r_j>1\), then \(\Upsilon_j=1\). Apply Theorem SI.14 and (SI.30).
□
