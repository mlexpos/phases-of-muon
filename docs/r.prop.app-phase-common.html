Proposition SI.2 (Common drift)
Assume (M1) with a finite index set, \(\mathfrak d_i=\mathfrak d>0\) for all \(i\) and \(\mathfrak v_{\rm tot}>0\). Then
\[ F(s)=F_0e^{-2\mathfrak ds},\qquad k(s)=\frac{\lr\mathfrak v_{\rm tot}}2e^{-2\mathfrak ds},\qquad \mathcal S=\frac{\mathfrak v_{\rm tot}}{2\mathfrak d}, \]
and the risk solves
\begin{equation}\tag{SI.11} \frac{\dif\fRisk}{\dif t}=-2\lr\mathfrak d\sqrt{\fRisk}+\frac{\lr^2\mathfrak v_{\rm tot}}2 . \end{equation}
Put \(a_\circ\defeq\lr\mathfrak d\), \(b_\circ\defeq\lr\mathfrak v_{\rm tot}/(4\mathfrak d)=\lr\mathcal S/2\) and \(u_0\defeq\sqrt{F_0}\).
  1. (i)
    If \(u_0\ne b_\circ\), then for every \(t\ge0\)
    \begin{equation}\tag{SI.12} a_\circ t=u_0-\sqrt{\fRisk(t)}+b_\circ\log\frac{\abs{u_0-b_\circ}}{\abs{\sqrt{\fRisk(t)}-b_\circ}} , \end{equation}
    and \(\sqrt{\fRisk}\) is strictly decreasing with limit \(b_\circ\) if \(u_0>b_\circ\), strictly increasing with limit \(b_\circ\) if \(u_0<b_\circ\), and never equal to \(b_\circ\). If \(u_0=b_\circ\), then \(\fRisk\equiv b_\circ^2\).
  2. (ii)
    Let \(a\ge0\). If \(F_0\le a\), then \(t_a=0\). If \(F_0>a\), then \(t_a<\infty\) if and only if \(a>b_\circ^2\), and then \(t_a\) is given by (SI.12) with \(\sqrt{\fRisk(t)}=\sqrt a\).
Proof.
Summing (SI.2) with weights \(\mu_i/2\) gives
\[ \frac{\dif\fRisk}{\dif t}=-\frac{\lr\mathfrak d}{\sqrt{\fRisk}}\sum_i\mu_i\fQ_i+\frac{\lr^2}2\sum_i\mu_i\mathfrak v_i =-2\lr\mathfrak d\sqrt{\fRisk}+\frac{\lr^2\mathfrak v_{\rm tot}}2 . \]
The formulas for \(F\), \(k\) and \(\mathcal S\) follow from (SI.3) and (SI.1) by finite summation. Since \(\mathcal S>0\), Theorem SI.2 gives a global solution with positive risk and \(\fRisk(t)\to b_\circ^2\). In the variable \(\mathsf u\defeq\sqrt{\fRisk}\) the relation (SI.11) reads
\[ \mathsf u'=-\frac{a_\circ(\mathsf u-b_\circ)}{\mathsf u} . \]
The function \(\mathsf w\defeq\mathsf u-b_\circ\) therefore satisfies \(\mathsf w'=-(a_\circ/\mathsf u)\mathsf w\), so that
\[ \mathsf w(t)=\mathsf w(0)\exp\Big(-a_\circ\int_0^t\frac{\dif t'}{\mathsf u(t')}\Big). \]
Thus \(\mathsf w\) keeps the sign of \(\mathsf w(0)\), \(\abs{\mathsf w}\) is strictly decreasing when \(\mathsf w(0)\ne0\), and \(\mathsf w\equiv0\) when \(\mathsf w(0)=0\). When \(\mathsf w(0)\ne0\), the equation is separable:
\[ \frac{\dif}{\dif t}\Big(\mathsf u+b_\circ\log\abs{\mathsf u-b_\circ}\Big)=\frac{\mathsf u}{\mathsf u-b_\circ}\,\mathsf u'=-a_\circ , \]
and integrating from \(0\) to \(t\) gives (SI.12). This proves (i).
For (ii), \(\fRisk(0)=F_0\) gives \(t_a=0\) when \(F_0\le a\). Let \(F_0>a\). If \(u_0>b_\circ\), the risk decreases strictly to \(b_\circ^2\) without reaching it, so it reaches \(a\) at a finite time exactly when \(a>b_\circ^2\), and that time solves (SI.12). If \(u_0\le b_\circ\), the risk never falls below \(F_0>a\), so \(t_a=\infty\), and in this case \(a<F_0\le b_\circ^2\).
□

theorem prop_app_phase_common_i [Fintype ι] (m : RowModel ι) (d : ℝ) (hd : 0 < d)
    (hdi : ∀ i, m.d i = d) (hv : 0 < commonVtot m) :
    (∀ s : ℝ, 0 ≤ s → m.forcing s = m.F0 * Real.exp (-(2 * d * s))) ∧
    (∀ s : ℝ, 0 ≤ s → m.kernel s = m.η * commonVtot m / 2 * Real.exp (-(2 * d * s))) ∧
    m.S = commonVtot m / (2 * d) ∧
    (∃ Q : ι → ℝ → ℝ, IsGlobalRowSolution m Q) ∧
    (∀ Q : ι → ℝ → ℝ, IsGlobalRowSolution m Q → ∀ t₁ : ℝ, ∀ t ∈ Ico (0 : ℝ) t₁,
      HasDerivWithinAt (m.risk Q)
        (-(2 * m.η * d) * Real.sqrt (m.risk Q t) + m.η ^ 2 * commonVtot m / 2)
        (Ico (0 : ℝ) t₁) t) ∧
    (∀ Q : ι → ℝ → ℝ, IsGlobalRowSolution m Q →
      (Real.sqrt m.F0 ≠ commonB m d →
        (∀ t : ℝ, 0 ≤ t →
          commonA m d * t = Real.sqrt m.F0 - Real.sqrt (m.risk Q t)
            + commonB m d * Real.log (|Real.sqrt m.F0 - commonB m d|
              / |Real.sqrt (m.risk Q t) - commonB m d|)) ∧
        (∀ t : ℝ, 0 ≤ t → Real.sqrt (m.risk Q t) ≠ commonB m d) ∧
        (commonB m d < Real.sqrt m.F0 →
          StrictAntiOn (fun t => Real.sqrt (m.risk Q t)) (Ici (0 : ℝ)) ∧
          Tendsto (fun t => Real.sqrt (m.risk Q t)) atTop (𝓝 (commonB m d))) ∧
        (Real.sqrt m.F0 < commonB m d →
          StrictMonoOn (fun t => Real.sqrt (m.risk Q t)) (Ici (0 : ℝ)) ∧
          Tendsto (fun t => Real.sqrt (m.risk Q t)) atTop (𝓝 (commonB m d)))) ∧
      (Real.sqrt m.F0 = commonB m d → ∀ t : ℝ, 0 ≤ t → m.risk Q t = commonB m d ^ 2)) := by
